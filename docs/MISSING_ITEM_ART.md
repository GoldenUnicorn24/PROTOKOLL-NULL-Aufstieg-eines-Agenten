# Fehlende Gegenstandsbilder

Stand v0.5.0-beta: **Alle 42 Gegenstände haben eine vorhandene Bilddatei** in `app/src/main/assets/items/` (32 Icons von game-icons.net, CC BY 3.0, sowie 6 eigene Originalicons).

Fehlt künftig eine Datei, zeigt die App einen neutralen Platzhalter mit der Asset-ID. Solche Fälle bitte hier eintragen, damit ein Mensch bzw. ein Bildwerkzeug außerhalb dieses Coding-Auftrags passende, lizenzierte Bilder ergänzen kann.

Mehrfach genutzte Icons (optional später eigene Motive):

| Icon-ID | Verwendet von |
|---|---|
| `radio` | Standard-Funkgerät, Verschlüsseltes Funkgerät |
| `pistol` | Trainingsmarkierer, Dienstausrüstung |
| `armor` | Leichte und schwere Schutzweste |
| `backpack` | Kleiner und großer Rucksack |
